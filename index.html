1 What TrustShield Checks

TrustShield analyzes web pages at three privacy-preserving tiers without reading sensitive page contents:

Tier 1: URL Structural Heuristics

Inspects the address string for deceptive evasion techniques:

  • Raw IP-based hostnames instead of registered domains
  • Deceptive @ credential tricks in URL authority
  • Obfuscated double-slash (//) redirect sequences
  • Excessive subdomain depth (> 3 levels)
  • High-risk disposable domain extensions (e.g., .tk, .ml, .xyz)
  • Suspicious keywords combined with risky TLDs

Tier 2: DOM Structural Signals

Analyzes page structure locally in the browser sandbox:

  • Presence of password input fields
  • Forms submitting data to external third-party domains
  • Cross-origin iframe density
  • Favicon origin consistency
  • Never reads passwords, text input, or cookies

Tier 3: Machine Learning Model

Evaluates an 11-dimensional feature vector:

  • Random Forest classifier with 200 estimators
  • Extracts non-linear feature interactions
  • Generates probabilistic phishing risk contribution
  • Operates offline with sub-50ms inference latency

4 What a Score Does (and Does NOT) Mean

0 – 39: Low Risk

Meaning: No critical credential-harvesting indicators or known threat matches were detected.
Limitation: Does not guarantee the site is benign. If marked with "Limited Evidence", the site lacked forms or reputation data (e.g. video streams, downloads, or unindexed domains).

40 – 69: Suspicious

Meaning: Concerning structural attributes detected (e.g., suspicious TLD with account keywords, excessive subdomains, or unencrypted credential prompts). Exercise caution.

70 – 100: High Risk

Meaning: Strong credential-theft behavior detected (e.g., password forms submitting data to an external third-party domain) or verified blacklist match. Do not enter credentials.

5 User Privacy & Data Protection

  • Zero Credential Ingestion: The extension content script queries counts only (forms.length, passwordInputs.length). It never inspects input.value or text nodes.
  • No Browsing History Stored: Scans run on-demand or at page load; URLs are not logged into persistent databases or sold to analytics brokers.
  • SSRF Defense-in-Depth: Backend validates all hostnames against RFC 1918, RFC 5737, loopback (127.0.0.0/8), link-local, and cloud metadata (169.254.169.254) addresses.
  • Offline Operation: Fully functional without external internet connectivity using local heuristics and bundled ML weights.

⚡ How Automatic Scanning Works

When navigating to a new eligible website, TrustShield's background service worker automatically analyzes the target using lightweight URL heuristics and DOM structure extraction.

  • Zero Interruption: Runs asynchronously without delaying page rendering.
  • Intelligent Deduplication: Scans each distinct hostname once per session; skips ordinary path navigation and reloads.
  • Bottom-Right Notification: A brief 5-second risk notification appears unobtrusively and auto-dismisses.

🎯 Explainable Risk Scoring

TrustShield never displays an opaque, uncalibrated score without evidence. Every verdict is backed by an auditable point attribution:

  • Signal Attribution: Exact numerical points assigned for each detected heuristic or DOM anomaly.
  • Machine Learning Context: Calibrated Random Forest model output with documented benchmark limits.
  • Honest Indicators: Absence of a blacklist match is explicitly noted as non-proof of safety.

Step-by-Step Installation ("Load Unpacked" Developer Mode)

Distribution Notice: TrustShield is open architecture security software currently distributed via clean unpacked bundle. Follow Chrome's developer loading workflow:

  1. Download & Extract: Download trustshield-extension.zip and extract the archive to a local folder.
  2. Open Extensions Page: In Chrome, open a new tab and navigate to chrome://extensions (or navigate via Menu → Extensions → Manage Extensions).
  3. Enable Developer Mode: Toggle on the Developer mode switch located in the upper-right corner.
  4. Click Load Unpacked: Click the Load unpacked button in the top-left toolbar.
  5. Select Folder: Select the extracted directory containing manifest.json.
  6. Done: Pin the TrustShield icon to your Chrome toolbar for one-click forensics and CERT dossier export!

Extension Permissions & Privacy Disclosures

TrustShield strictly adheres to least-privilege principles. We explicitly disclose why each permission is required:

Permission Technical Justification Privacy Impact
webNavigation Detects top-level domain navigation to initiate automatic security checks on new hostnames. No navigation history is logged, transmitted, or persisted.
activeTab Inspects structural DOM attributes (e.g., cross-origin form actions) on the current webpage. Never reads input values, passwords, or text contents.
storage Caches scan results in local browser memory to avoid redundant scans. Stored locally on your device; never sent to third parties.
scripting Injects the isolated 5-second risk notification into a sandboxed Shadow DOM. Isolated from host webpage scripts and CSS.
declarativeNetRequest Enables client-side threat blocking when critical phishing is detected. Operates entirely in browser memory.

7 Reporting Incorrect Classifications

Phishing detection is an evolving adversarial domain. If you encounter an institutional portal incorrectly flagged (false positive) or a deceptive lure that was not detected (false negative):

Please open an issue on the TrustShield repository with:

  1. The sanitized domain name (e.g., example[.]edu)
  2. The risk score and signals displayed
  3. The expected classification and reason
